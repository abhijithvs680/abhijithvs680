## About me

I am an AI and software engineer with **3 years of experience**, including **2.5 years building production agentic AI and backend systems** for Vizru's enterprise zero-code platform. I work across the stack—from LLM orchestration and secure data access to real-time WebSocket services, distributed backend systems, and React interfaces.

My focus is practical AI engineering: systems that are secure, measurable, cost-efficient, and reliable in production.

## What I build

- **Agent platforms** — tool-calling runtimes, long-term memory, model routing, guardrails, and multi-channel integrations
- **MCP and data infrastructure** — multi-tenant MCP servers, safe SQL access, JSON-RPC APIs, and relational data layers
- **RAG systems** — multimodal ingestion, pgvector, hybrid retrieval, reciprocal-rank fusion, and grounded responses
- **Real-time voice AI** — low-latency WebSocket audio, Gemini Live, OpenAI Realtime, interruption handling, and in-call tools
- **Backend and full-stack products** — Python, FastAPI, PHP, React, PostgreSQL, MongoDB, Redis, Celery, and Docker
